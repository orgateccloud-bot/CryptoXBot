PASSO 1 — ACESSAR O PAINEL DE API
--------------------------------------------------------------------
1. Acesse binance.com e faça login
2. Clique na sua foto/avatar (canto superior direito)
3. Vá em: Gerenciamento de API  →  Criar API
4. Escolha: "API gerada pelo sistema"
5. Dê um nome (ex: "BinanceXBot")
6. Complete a verificação 2FA

PASSO 2 — CONFIGURAR AS PERMISSÕES (CRÍTICO — MENOR PRIVILÉGIO)
--------------------------------------------------------------------
O bot executa ordens APENAS no mercado SPOT (/api/v3/order).
Os dados de Futures (funding/open interest) usados como sentimento
são endpoints PÚBLICOS — não exigem permissão nenhuma.

Ative APENAS:

  [x] Habilitar leitura                      ← necessário
  [x] Habilitar Trading Spot e de Margem     ← necessário para operar SPOT

Deixe DESATIVADO (sempre):

  [ ] Habilitar trading de Futuros           ← o bot NÃO opera futuros;
                                                ativar isso só amplia o
                                                estrago se a chave vazar
  [ ] Habilitar saques                       ← NUNCA ATIVE
  [ ] Habilitar transferências internas      ← NUNCA ATIVE
  [ ] Permitir empréstimo/margem             ← NUNCA ATIVE

PASSO 3 — RESTRINGIR POR IP (OBRIGATÓRIO PARA MODO REAL)
--------------------------------------------------------------------
Na opção "Restrição de acesso":

  Selecione: "Restringir acesso a IPs confiáveis"

  Adicione APENAS o IP fixo da máquina que roda o worker
  (VPS ou PC). Ao migrar de máquina, adicione o IP novo e
  REMOVA o antigo no mesmo momento.

  Sem restrição de IP, a Binance ainda aceita a chave de qualquer
  lugar do mundo — não pule este passo.

PASSO 4 — ONDE COLOCAR AS CHAVES
--------------------------------------------------------------------
As chaves vão no arquivo .env (NUNCA em código, NUNCA no Git):

  BINANCE_API_KEY=sua_api_key_aqui
  BINANCE_API_SECRET=sua_secret_key_aqui

A Secret Key é exibida UMA única vez na criação — copie na hora.
Em produção o .env fica em /opt/binancexbot/.env (fora do Git).

REGRAS DE SEGURANÇA — NUNCA QUEBRE ESTAS REGRAS
--------------------------------------------------------------------
* NUNCA compartilhe suas chaves com ninguém (nem em chat com IA)
* NUNCA envie o .env por WhatsApp, email ou qualquer chat
* NUNCA faça commit do .env (o .gitignore protege — não remova a linha)
* Se suspeitar de exposição: REVOGUE IMEDIATAMENTE na Binance
  (botão "Excluir" na chave, no painel de API) e gere outra
* Lembrete do modo real: além das chaves, o bot só envia ordem real
  com DRY_RUN=false + ALLOW_REAL_TRADING=true + ENV=production —
  e SOMENTE após o GATE_GO_LIVE.md estar integralmente aprovado

VERIFICAR SE ESTÁ FUNCIONANDO
--------------------------------------------------------------------
Após preencher o .env, rode:

  python testar_api.py

Se aparecer seu saldo spot, está tudo certo.
